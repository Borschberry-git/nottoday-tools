# NotToday: инструменты

Страницы рабочих инструментов настольной игры NotToday. Только интерфейсы: правила игры и документы живут в отдельном репозитории.

- `cards/` — конструктор карт «Пятницы» (места, события, общая база).
- `pyatnica/` — стол «Пятницы» (`index.html`: сборы, улица, колода событий из базы), генератор персонажей (`generator.html`), стек карт вещей (`veshchi.html`). Источник — `prototype/pyatnica/persona/` в основном репозитории, собирается `build.py`.
